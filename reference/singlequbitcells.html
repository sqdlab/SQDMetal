Single Qubit Cells

class SingleQubitCells(design, sim_dir, user_options, mesh=None, exclude='feedline|LP_', feedline_stub='500um', chip_margin_mm=0.6, name='cell', verbose=False)

Bases: object

Single-qubit capacitance simulations built from a full chip design.

For each qubit, every component linked to it through pin_inputs (e.g. readout meander and coupling tee) is copied into a small design with the same class and a deep copy of the chip’s options, so the cell cannot drift from the chip. Open-ended feedline stubs are added to coupling tees (CoupledLineTee), and the copied geometry is checked against the chip.

Capacitance-matrix conductors are identified by geometry (ground / pad1 / pad2 / res / feed), because the order Palace receives depends on where the shapes sit rather than on the order components were created. Each simulation saves conductors.png showing the mapping.

Typical use:

cells = SingleQubitCells(design, "sims", user_options=dict(palace_dir="...", num_cpus=8))
rec = cells.simulate("Q1")                       # meshes, runs Palace (cached), saves conductors.png
p = cells.params("Q1", f_q_GHz=5.0, f_r_GHz=7.0) # calc_params_floating_Transmon_from_files output
Parameters:

  • design (QDesign) – The full chip design (already built).

  • sim_dir (str or Path) – Folder holding one sub-folder per simulated cell.

  • user_options (dict) – Palace user_options (palace_dir, num_cpus, solver_order, …).

  • mesh (dict, optional) – Keyword arguments for fine_mesh_components (min_size, max_size, …), in metres.

  • exclude (str) – Regex of component names never pulled into a cell (e.g. a feedline shared by all qubits).

  • feedline_stub (str) – Length of the open-ended feedline kept either side of each coupling tee.

  • chip_margin_mm (float) – Substrate margin around the cell.

  • name (str) – Prefix for simulation folder names (<name>_<label>_cap).

  • verbose (bool) – If False, build/meshing printouts are suppressed (Palace’s own output is not).

cell(qubit)

The cell for qubit: Dict(design, components, stubs, geometry_difference_mm2). Built once and checked against the full chip (raises if any copied component’s geometry differs).

static check_geometry(full, sub, names, tol_mm2=1e-09)

Largest symmetric-difference area (design units^2) between full and sub for each of names (metal and cut-outs). Raises AssertionError above tol_mm2.

components(qubit, layer='1')

Components linked to qubit through pin_inputs (either direction) on layer, in the design’s creation order. Raises if the cell reaches another qubit.

static corrected_design_frequency(f_target_GHz, f_design_used_GHz, f_predicted_GHz)

Frequency to pass to the chip builder so the resonator lands on f_target_GHz: the builder’s length scales as 1 / f_design and f_predicted ~ f_design locally, so f_design_new = f_target * f_design_used / f_predicted (one step is exact to first order; re-simulate the capacitance once to confirm).

static design_from_notebook(path, stop_marker, verbose=False)

Runs a design notebook’s code cells (lines starting with % or ! skipped) up to and including the first cell containing stop_marker, in the notebook’s folder, and returns its namespace (e.g. ns['design']). Keeps the chip notebook as the single source of truth for its options.

eigenmode(qubit, L_J_nH, kinetic_inductance_pH_sq=0.0, label=None, start_freq_GHz=1.0, n_modes=3, C_J_fF=0.0, f_r_GHz=None, epr_interfaces=True, mesh=None, user_options=None, run=True, force_rerun=False)

Eigenmode simulation of the cell of qubit with the junction as a lumped inductor L_J_nH, 50 Ohm ports at the ends of the feedline stubs (so the resonator and qubit are loaded as on the chip) and, if kinetic_inductance_pH_sq > 0, a kinetic sheet inductance (pH/square) on all metal. Results are reused when the cell, junction, kinetic inductance and solver settings are unchanged.

Inputs:

  • start_freq_GHz, n_modes - the solver finds n_modes modes above start_freq_GHz

  • f_r_GHz - expected (bare) resonator frequency, used only to pick the resonator mode

  • epr_interfaces - also compute surface participations (Si-vacuum, Si-Al, Al-vacuum)

  • mesh, user_options - override this object’s mesh / Palace settings for this run

Returns a dict: modes (DataFrame: f_GHz, Q, kappa_MHz, EPR_JJ per mode), qubit_mode / resonator_mode (1-based), summary (dressed f_q and f_r, anharmonicity, cross-Kerr chi_qr, kappa_r, T1 limits), epr (the full output of calculate_hamiltonian_parameters_EPR), output_dir and status.

static eigenmode_results(folder, qubit_mode=None, f_r_GHz=None)

Reads an eigenmode simulation folder (made by eigenmode()): mode table, EPR Hamiltonian parameters and a summary for the qubit mode (largest junction participation unless given) and the resonator mode (nearest f_r_GHz if given, else the other mode with the most junction participation).

fingerprint(qubit)

Short hash of the layer-1 geometry that sets qubit’s capacitances: the class and options of every component in its cell (the junction, on another layer, is not included). Store it with simulation results to tell later whether the chip’s geometry has changed since.

static fit_resonator_capacitance(length_mm, C_res_fF)

Straight-line fit C = C’ l + C_0 of simulated resonator capacitances against resonator length.

The capacitance of one meshed resonator scatters by about 1 % from mesh to mesh (enough to move its frequency by tens of MHz), while C’ (the line) and C_0 (end loading, nearly the same for every resonator of a chip) are smooth. Fitting all simulated resonators averages the mesh scatter out. Returns a dict with C_per_mm_fF, C0_fF, rms_pct (scatter of the points about the fit) and n.

static fitted_capacitance_fF(fit, length_mm)

Resonator capacitance (fF) at length_mm from a fit_resonator_capacitance fit.

static ground_contact(design, component, fillet_resolution=12)

Point (x, y) where component’s rendered (filleted) metal touches the ground plane, or None. The ground plane is the chip minus every rendered cut-out, as built for simulation.

static identify_conductors(sub, qubit, resonator, stubs, terminals)

Maps capacitance-matrix indices (order of terminals, i.e. sim._cur_cap_terminals) to roles by geometry: ground (largest), res (nearest the resonator component), feed (nearest the first feedline stub) and pad1/pad2 (the remaining conductors touching the qubit; pad1 is nearer the qubit’s ‘readout’ pin). resonator / stubs may be None / empty for cells without them.

static junction_for(f01_GHz, E_C_GHz, ng=0.25)

Junction giving a transmon with charging energy E_C_GHz the transition frequency f01_GHz, solved numerically (charge basis, see transmon_levels) rather than with the asymptotic sqrt(8 E_J E_C) - E_C. Returns dict(E_J_GHz, L_J_nH, E_J_over_E_C, f01_GHz, alpha_MHz).

static metal_geom(design, name, subtract=False, layer='1')

Union of a component’s geometry on layer (paths buffered to their width); subtract=True gives its ground-plane cut-outs instead.

params(qubit, f_q_GHz, f_r_GHz=None, res=None, C_J_fF=0.0, print_all_capacitances=False)

Circuit parameters from the simulated cell, via PALACE_Capacitance_Simulation.calc_params_floating_Transmon_from_files with the detected conductor indices. The resonator is res if given, else a half-wave resonator at f_r_GHz.

classmethod plot_conductors(terminals, idx, ax, title='')

Draws each conductor coloured by role, marked with its 0-based capacitance-matrix index.

static predict_resonator(calibration, length_mm, C_res_fF, pull_GHz=0.0)

Resonator frequency (GHz, linear mode incl. the qubit’s pull) predicted from a resonator_calibration for a resonator of length length_mm and capacitance C_res_fF.

qubit_names()

Names of every qubit component (BaseQubit subclasses) in the design.

static qubit_pull_GHz(f_r_GHz, f_q_GHz, g_MHz)

Linear (normal-mode) pull of the resonator by the qubit, g^2 / (f_r - f_q), in GHz (positive when the resonator is above the qubit). This is the shift a linear eigenmode solve already contains.

static resonator_calibration(f_r_eig_GHz, length_mm, C_res_fF, pull_GHz=0.0, **info)

Calibration of all resonators of a chip from one eigenmode simulation. A lambda/2 CPW resonator of inductive length l and total capacitance C (line + end loading) sits at f = 1 / (2 sqrt(L’ l C)) = K / sqrt(l C), with K = 1 / (2 sqrt(L’)). L’ is the inductance per length (geometric + kinetic), the same for every resonator with this CPW and film. K is fixed from the resonator mode of an eigenmode run, with the qubit’s linear pull removed. Returns a dict (JSON-serialisable) with K and the inputs; extra info is kept.

resonator_capacitance_fF(qubit)

Total (Maxwell self-) capacitance of the resonator conductor of qubit from its capacitance simulation, in fF: the line’s capacitance to ground plus its end loading (the qubit pad and the feedline coupler).

static resonator_length_for(calibration, fit, f_GHz, pull_GHz=0.0)

Resonator length (mm) that puts the resonator at f_GHz (linear mode incl. the qubit’s pull): the positive root of K / sqrt(l (C’ l + C_0)) + pull = f, i.e. C’ l^2 + C_0 l - (K / (f - pull))^2 = 0. calibration must have been made with the fitted capacitance (see fitted_capacitance_fF).

resonator_length_mm(qubit)

Centre-line length (mm) of the readout resonator of qubit: the routed resonator(s) in its cell, plus the coupled arm of each CoupledLineTee (trace second_cpw, along its fillet) and the qubit’s readout wire (get_resonator_length_mm) where those exist.

simulate(qubit, label=None, run=True, force_rerun=False)

Meshes and (if run) simulates the cell of qubit with Palace. Results are reused when the cell geometry and physics settings are unchanged (unless force_rerun). Saves conductors.png (matrix index -> conductor) in the simulation folder.

Returns a dict: key, qubit, components, conductor_indices, output_dir, plot, created and status (‘simulated’, ‘cached’ or ‘prepared’).

to_catalogue(catalogue, qubit, f_q_GHz=None, f_r_GHz=None, res=None, C_J_fF=0.0, overwrite=False)

Saves the simulated cell of qubit as an entry of a QubitCatalogue (see QubitCatalogue.add_simulation): the qubit’s full options from the chip, the cell / mesh / solver settings, the conductor mapping and the small result files. If f_q_GHz and a resonator (f_r_GHz or res) are given, g, chi, Delta, anharmonicity, kappa and the Purcell limit are stored too (as result.* columns). Returns the catalogue key.

static transmon_levels(EJ, EC, ng=0.25, ncut=20)

Lowest transmon energy levels (relative to the ground state, units of EJ/EC) from H = 4EC(n - ng)^2 - EJ cos(phi) in the charge basis.
